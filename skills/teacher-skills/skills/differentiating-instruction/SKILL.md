# Differentiating Instruction

## When to use this skill

When one lesson or assignment needs to work for students at genuinely different skill levels.

## Workflow

1. Identify the core learning objective that must stay constant across all versions
2. Create a scaffolded version for students who need more support (simplified language, worked examples, chunked steps)
3. Create an extension version for advanced students (added complexity, open-ended application, less scaffolding)
4. Keep the assessment aligned across versions so all students are evaluated against the same core objective
5. Note where students might move between versions mid-lesson

## Key points

- The learning objective stays identical across every version — only the scaffolding and complexity change
- Scaffolded doesn't mean lower expectations, it means more support reaching the same target
- Extension work should deepen or apply the concept, not just add more of the same
- Keep versions similar enough in structure that classroom logistics stay manageable

## Sample prompts

**Example 1:** Differentiate this fractions worksheet for a class with a wide skill range

**Example 2:** Adapt this reading comprehension assignment for a student reading two grade levels behind

**Example 3:** Create an extension activity for students who finish the main assignment early

## Output format

Core Objective (unchanged) → Scaffolded Version → Standard Version → Extension Version, each with matching assessment criteria.
