# Writing Lesson Plans

## When to use this skill

When you need a complete, standards-aligned lesson plan for an upcoming class.

## Workflow

1. Confirm subject, grade level, and the specific standard or learning objective
2. Write a clear, measurable learning objective ('Students will be able to...')
3. List required materials and any prep needed before class
4. Break the lesson into timed segments: hook, instruction, guided practice, independent practice, closure
5. Build in a formative check for understanding partway through, not just at the end
6. Add differentiation notes for struggling and advanced students
7. Include the exit ticket or closing assessment

## Key points

- Objectives should be observable and measurable, not vague ('understand fractions' vs 'solve 5 fraction addition problems with unlike denominators')
- Time-box every segment — a plan without timing is not usable on the day
- Always include a formative check before the end of class, not only a final assessment
- Differentiation should be built into the plan, not an afterthought

## Sample prompts

**Example 1:** Write a 45-minute lesson plan on photosynthesis for 7th grade science

**Example 2:** Create a lesson plan introducing the water cycle to 3rd graders

**Example 3:** Plan a middle school English class on identifying theme in short stories

## Output format

Lesson Plan: Objective → Materials → Timed Activity Sequence → Formative Check → Differentiation Notes → Exit Ticket.
