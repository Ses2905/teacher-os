# Writing Student Feedback

## When to use this skill

When you need to write feedback on student work or a report card comment quickly, without it sounding generic.

## Workflow

1. Note the specific strengths visible in this piece of work — not generic praise
2. Identify one or two concrete, actionable next steps, not a long list
3. Write in a tone appropriate to the student's age and the audience (student vs. parent)
4. Anchor every comment to specific evidence from the work, not a general impression
5. End on a forward-looking note the student can act on

## Key points

- 'Good job' is not feedback — name specifically what worked and why it worked
- Limit next steps to one or two — a long list of fixes overwhelms rather than helps
- Keep the tone matched to age: report card language for parents differs from in-class feedback to the student directly
- Every piece of feedback should point to something the student can actually do differently next time

## Sample prompts

**Example 1:** Write report card comments for a 4th grader who is strong in reading but struggles with math word problems

**Example 2:** Give feedback on this student essay draft, focused on argument structure

**Example 3:** Write an encouraging but honest progress note for a student falling behind in class participation

## Output format

Feedback: Specific Strength(s) → 1-2 Concrete Next Steps → Encouraging Forward-Looking Close.
