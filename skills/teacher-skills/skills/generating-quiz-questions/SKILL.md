# Generating Quiz Questions

## When to use this skill

When you need assessment questions written quickly for a specific topic and difficulty level.

## Workflow

1. Confirm the topic, grade level, and desired mix of question formats
2. Distribute questions across cognitive levels — recall, application, analysis — not all at one level
3. Write multiple choice distractors that reflect common misconceptions, not obviously wrong answers
4. Write clear, unambiguous question stems with no trick wording
5. Produce a complete answer key with brief rationale for each answer
6. Flag any questions that assume knowledge outside the stated scope

## Key points

- A good distractor represents a real misconception, not a random wrong answer — this is what makes multiple choice diagnostic
- Mix cognitive levels deliberately: a quiz of only recall questions doesn't test real understanding
- Every question should be answerable using only what was actually taught
- Always generate the answer key alongside the questions, not as an afterthought

## Sample prompts

**Example 1:** Write a 10-question quiz on World War 2 causes for 10th grade history

**Example 2:** Create 5 multiple choice questions on cell division with realistic distractors

**Example 3:** Generate a short answer test on the causes of the French Revolution

## Output format

Quiz: Questions organised by format and difficulty, followed by a complete Answer Key with brief rationale per answer.
