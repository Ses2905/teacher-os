# Writing IEP Progress Notes

## When to use this skill

When you need to document progress toward IEP goals from classroom observations in the required format.

## Workflow

1. Confirm the specific IEP goal being reported on and its measurable target
2. Gather factual classroom observations and any data collected (accuracy rates, frequency counts, work samples)
3. State current performance against the goal using specific, measurable language
4. Note progress trend: on track, needs adjustment, or goal met
5. List any accommodations used and their observed effect
6. Flag anything requiring the IEP team's review rather than resolving it here

## Key points

- Every statement should be tied to observed evidence or collected data, never a general impression
- This drafts administrative documentation only — it does not replace a special education professional's clinical judgment, evaluation, or the IEP team's decision-making
- Use the measurable language from the original goal, not paraphrased approximations
- Flag ambiguous or concerning patterns for the IEP team explicitly rather than making the call in the note

## Sample prompts

**Example 1:** Draft a quarterly progress note for an IEP reading fluency goal based on these running record scores

**Example 2:** Write a progress update on a math goal showing improvement with accommodations

**Example 3:** Document accommodation effectiveness for extended time on tests this term

## Output format

Progress Note: Goal Restated → Current Performance (with data) → Trend → Accommodations & Effect → Items for IEP Team Review.
