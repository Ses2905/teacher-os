# Planning Classroom Activities

## When to use this skill

When you need an interactive activity that reinforces a specific concept, not just fills class time.

## Workflow

1. Confirm the learning objective the activity must reinforce
2. Choose an activity format matched to class size, age, and available time
3. Write clear setup instructions and materials needed
4. Write the rules or steps in the exact sequence students will follow
5. Build in a debrief question connecting the activity back to the learning objective
6. Note a simpler backup version in case the activity runs short or long

## Key points

- An activity earns its class time only if it reinforces the actual objective, not just engagement for its own sake
- Instructions need to be followable by a student reading them cold, not just by the teacher who designed them
- Always include a debrief step — without it, the activity risks being fun but disconnected from learning
- Have a backup for timing, since activities rarely run exactly as planned

## Sample prompts

**Example 1:** Design a group activity to reinforce the parts of speech for 5th graders

**Example 2:** Create a review game for a unit test on the periodic table

**Example 3:** Plan a hands-on activity teaching supply and demand for high school economics

## Output format

Activity Plan: Objective → Materials & Setup → Step-by-Step Rules → Debrief Questions → Timing Backup Plan.
