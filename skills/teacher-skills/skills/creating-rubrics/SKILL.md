# Creating Rubrics

## When to use this skill

When you need a clear, consistent grading rubric before assigning or grading student work.

## Workflow

1. Identify the assignment type and the skills actually being assessed
2. Define 3-5 criteria that reflect what mastery looks like for this task
3. Write 4 performance levels per criterion (e.g., Exceeds, Meets, Approaching, Below)
4. Write specific, observable descriptions for each level — not just 'good' vs 'poor'
5. Assign point values or weights per criterion
6. Check that a student could self-assess accurately using only the rubric

## Key points

- Every level description should be specific enough that two graders would score the same paper the same way
- Avoid vague language like 'good effort' — describe what the work actually contains at each level
- Weight criteria by what matters most for this specific assignment, not evenly by default
- A rubric a student can't use to improve their own work before submitting isn't finished yet

## Sample prompts

**Example 1:** Create a rubric for a 5-paragraph persuasive essay, 8th grade

**Example 2:** Build a grading rubric for a group science fair project

**Example 3:** Write a rubric for a class presentation, including delivery and content

## Output format

Rubric table: Criteria (rows) × Performance Levels (columns), each cell with a specific observable description, plus point values.
